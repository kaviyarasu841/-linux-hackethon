# Task 1 - Nginx Server Setup

## Objective
Set up an Nginx server on Ubuntu and serve the custom HTML page provided by the organizers.

## Completed Steps

1. Installed Nginx on Ubuntu.
2. Started the Nginx service.
3. Downloaded the custom HTML page provided by the organizers.
4. Copied the HTML page to `/var/www/html/index.html`.
5. Tested the Nginx configuration using `sudo nginx -t`.
6. Reloaded Nginx.
7. Verified the hosted page using `curl http://localhost`.

## Result

The organizer-provided HTML page was successfully hosted using Nginx.

## Verification

The page displayed:

- Linux Community - OpenHack Hackathon
- Conducted on October 8th, 2026
- Name field
- Roll No field
- Good luck message
